# ورتل (Wartil)

تطبيق ويب تفاعلي لتعلّم أحكام التجويد وتصحيح تلاوة القرآن الكريم، مبني بـ React وTypeScript وVite.

## المزايا

- **تصميم فاخر متعدد الثيمات**: أربع سمات مختارة بعناية — «العاجي الذهبي» و«ليل الزمرد» و«ورق المصحف» و«الليل الملكي» — مع خطاطات زخرفية (ختم ثماني)، وخط عرض خطي (عارف رقعة)، وتبديل فوري محفوظ في المتصفح، واحترام تفضيل النظام الداكن تلقائيًا عند أول زيارة.
- **أحكام التجويد** (`/lessons`): شرح 17 حكمًا — أحكام النون الساكنة والتنوين، الميم الساكنة، الإدغام المتجانس والمتقارب، المدود الأربعة، القلقلة، الغنة، واللام الشمسية وهمزة الوصل والحروف الصامتة — مع المقدار بالحركات لكل حكم، وأمثلة قرآنية حيّة ملوّنة واختبار قصير لكل حكم.
- **المصحف الملوّن** (`/quran`): تصفح القرآن كاملًا بالتشكيل مع تلوين تلقائي لكل حكم تجويدي وفق لوحة ألوان alquran.cloud الرسمية، ومعاني الألوان، واستماع لتلاوة الشيخ مشاري العفاسي.
- **التلاوة والتصحيح الصوتي** (`/practice`): سجّل تلاوتك من الميكروفون، ويقوم نموذج **Whisper** (عبر [`@huggingface/transformers`](https://github.com/huggingface/transformers.js)) بتحويلها إلى نص **بالكامل داخل المتصفح** (لا يُرسل صوتك لأي خادم)، ثم تتم مقارنتها بالنص الصحيح كلمة بكلمة (محاذاة Needleman-Wunsch مع تطبيع التشكيل والهمزات)، مع تمييز الكلمات الصحيحة/المختلفة/الناقصة/الزائدة ونصائح تجويدية للمواضع التي تحتاج انتباهًا.
- **تقدّمي** (`/progress`): رسم بياني لتطور دقة التلاوة عبر الزمن، تتبّع الدروس المكتملة، وعدد أيام المواظبة المتتالية — كل ذلك محفوظ محليًا في المتصفح.

## المصدر

النصوص القرآنية والتشكيل وترميز أحكام التجويد وملفات الصوت تُجلب من [alquran.cloud](https://alquran.cloud) (واجهة `quran-tajweed` وaudio CDN الخاصة بـ Islamic Network).

## التقنيات

- React 19 + TypeScript + Vite
- Tailwind CSS 4
- React Router
- Zustand (مع `persist` في localStorage)
- Recharts
- `@huggingface/transformers` (Whisper ASR يعمل عبر Web Worker + WASM/ONNX Runtime Web داخل المتصفح)

## التشغيل محليًا

```bash
npm install
npm run dev
```

```bash
npm run build   # بناء الإنتاج
npm run lint    # فحص الكود
```

> ملاحظة: عند أول استخدام لصفحة "التلاوة والتصحيح"، يقوم المستخدم بتحميل نموذج Whisper (~عشرات الميجابايتات) مرة واحدة؛ يُخزَّن مؤقتًا في المتصفح للاستخدامات التالية.
